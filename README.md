# review-log ブランチ (回顧・展望・検証の記録専用)

このブランチは main と履歴を共有しない独立ブランチ。売買コード・状態ファイル・戦略ポリシーは一切含まず、
main を読み取って結果をここに書くだけ。ここへの push はどのワークフローも起動しない(push トリガーは全て main 限定)。

- `log/YYYY-MM-DD.json` … その日の事実(決済・損益・保有・判定・資金・実行間隔)、前営業日の展望の答え合わせ、回顧/展望/検証の本文
- `review_log.csv` … 1日1行の集計(展望的中・損益・損失数・実行間隔・価格照合の有無)。月次振り返りで使う
- `review_tool.py` … snapshot / add-review / summary。標準ライブラリのみ(jpholiday があれば祝日判定に使う)

毎日の確認ルーチン(平日15:50 JST)が更新する。2026-11-26 オーナー承認で開始。
